> **مدير حياتك اللي مش بينسى** | نظام إدارة حياة شخصي متكامل (Life OS)، محلي بنسبة 100%، أوفلاين، وبدون أي مكتبات أو تبعيات خارجية.

## 📖 عن المشروع

**كُـلّـه (Kollo)** هو تطبيق ويب محلي خفيف وشامل مصمم لإدارة كل تفاصيل الحياة اليومية (المهام، المشاريع، الميزانية، الصحة، العادات، التقويم، المذكرات، العلاقات، والمزيد) مباشرة من متصفحك، مع خصوصية تامة وحفظ كامل للبيانات داخل قاعدة بيانات متصفحك (`IndexedDB`).

التطبيق مدعوم بمساعد ذكاء اصطناعي محلي يُدعى **«الأسطى»** يدعم استدعاء الأدوات (`Tool Calling`)، التفكير المتسلسل، وتوليد التحليلات المالية والشخصية من واقع بياناتك الفعلية دون اختلاق أرقام.

---

## ✨ المميزات الرئيسية

- 🔒 **محلي وأوفلاين 100% (Offline-First)**: لا يوجد خادم خارجي، بياناتك بالكامل في `IndexedDB` على جهازك مع دعم التصدير والاستيراد المشفر (AES-GCM).
- ⚡ **بدون أدوات بناء (Zero-Build Zero-Dependencies)**: جافاسكريبت أصيل وCSS قياسي، يعمل فور فتح `index.html` في أي متصفح حديث.
- 🎨 **تصميم أصيل ومحسوب (Anti-AI-Slop)**: تصميم موجه للمستخدم البسيط، بعيد عن القوالب المكررة والبهارج المصطنعة، مع تجربة هاتف فائقة السلاسة ووضوح طباعي عربي راقٍ.
- 🧠 **محرّك الأسطى (AI Agent)**:
  - دعم أصيل لنماذج Google Gemini و OpenRouter ومزودي OpenAI-compatible.
  - 112 أداة للتحكم والاستعلام عن المهام، المصاريف، التقويم، والمذكرات.
- 📊 **أقسام متكاملة**: المهام، الميزانيات، العادات، التقويم، الصحة، المذكرات، البيت، والتحليلات.

## 📁 الهيكل المجلداتي وملفات التوجيه

```
كله-kollo/
├── index.html                 # المدخل الرئيسي للتطبيق
├── AGENTS.md                  # القواعد المعمارية الصارمة (حد الـ 200 سطر، SRP)
├── DESIGN.md                  # فلسفة التصميم ونظام الهوية البصرية (Anti-Slop)
├── MEMORY.md                  # سجل القرارات التراكمية وسياق التطوير
├── css/                       # ملفات التصميم القياسية
│   ├── tokens.css             # متغيرات التصميم والألوان والثيمات
│   ├── base.css               # الضبط الأساسي والخطوط ودعم RTL
│   └── components/            # عناصر الواجهة (البطاقات، الحقول، النوافذ)
├── js/
│   ├── core/                  # النواة الأساسية (DB, Router, UI, Storage)
│   ├── features/              # الميزات (Palette, Shortcuts, Backup)
│   ├── ai/                    # محرك الأسطى والـ Agent Loop
│   ├── tools/                 # أدوات استدعاء الوظائف (112 أداة)
│   └── modules/               # شاشات المودولات الـ 21
```

## 🚀 طريقة التشغيل

1. افتح ملف `index.html` مباشرة في أي متصفح ويب حديث.
2. لا يتطلب أي خادم أو تثبيت لـ `Node.js` أو `npm`.
