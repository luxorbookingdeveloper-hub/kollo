# كُـلّـه — Kollo 🌟
> **مدير حياتك اللي مش بينسى** | نظام إدارة حياة شخصي متكامل (Life OS)، محلي بنسبة 100%، أوفلاين، وبدون أي مكتبات أو تبعيات خارجية.

---

## 📖 عن المشروع

**كُـلّـه (Kollo)** هو تطبيق ويب محلي خفيف وشامل مصمم لإدارة كل تفاصيل الحياة اليومية (المهام، المشاريع، الميزانية، الصحة، العادات، التقويم، المذكرات، العلاقات، والمزيد) مباشرة من متصفحك، مع خصوصية تامة وحفظ كامل للبيانات داخل قاعدة بيانات جهازك (`IndexedDB`).

التطبيق مدعوم بمساعد ذكاء اصطناعي محلي يُدعى **«الأسطى»** يدعم استدعاء الأدوات (`Tool Calling`)، التفكير المتسلسل، وتوليد التحليلات المالية والشخصية من واقع بياناتك الفعلية دون اختلاق أرقام.

---

## ✨ المميزات الرئيسية

- 🔒 **محلي وأوفلاين 100% (Offline-First)**: لا يوجد خادم خارجي، لا يوجد تتبع، بياناتك بالكامل في `IndexedDB` على جهازك مع دعم التصدير والاستيراد المشفر (AES-GCM).
- ⚡ **بدون أدوات بناء (Zero-Build Zero-Dependencies)**: جافاسكريبت أصيل وCSS قياسي، يعمل فور فتح `index.html` في أي متصفح حديث.
- 🧠 **محرّك الأسطى (AI Agent)**:
  - دعم أصيل لنماذج Google Gemini و OpenRouter ومزودي OpenAI-compatible.
  - 112 أداة للتحكم والاستعلام عن المهام، المصاريف، التقويم، والمذكرات.
  - دعم الستريمنج (SSE) وبصمات التفكير (`Thought Signatures`).
- 🎨 **تصميم عصري متفاعل**:
  - ثيمات متعددة: تلقائي، داكن، فاتح، وريترو تسعينات.
  - دعم كامل للغة العربية واتجاه RTL.
  - كوماند باليت وبحث شامل (`Ctrl+K` أو مرتين مسافة).
  - اختصارات كيبورد لكافة العمليات وشرايط إنجازات (12 وسامًا).
- 📊 **أقسام متكاملة تغطي كل جوانب الحياة**:
  - **النهاردة**: لوحة تركيز يومية وحساب الحمل الذهني.
  - **المهام والمشاريع**: عرض قائمة، كانبان، ومصفوفة أيزنهاور.
  - **الفلوس والميزانيات**: تتبع المعاملات، الحسابات، الديون، الجمعيات، وحساب الزكاة.
  - **العادات والتقويم**: سلاسل الالتزام (Streaks) وخريطة حرارية وتقويم شهري.
  - **المذكرات والتعلم**: شبكة دلالية، كروت استذكار متباعد (SM-2)، وتتبع قراءة الكتب.
  - **الصحة والمزاج**: تتبع الأدوية ومخزونها، تسجيل المزاج، وجورنال الامتنان.
  - **البيت والعلاقات**: الأصول، الضمانات، الفواتير، ومتابعة صلة الرحم والتواصل.
  - **الحبشتكنات**: محرك أوتوميشن وقواعد تلقائية ذكية.

## 📁 الهيكل المجلداتي

```
كله-kollo/
├── index.html                 # المدخل الرئيسي للتطبيق
├── css/                       # ملفات التصميم
│   ├── tokens.css             # متغيرات التصميم والألوان والثيمات
│   ├── base.css               # الضبط الأساسي ودعم RTL
│   └── components.css         # عناصر الواجهة (البطاقات، الأزرار، النوافذ)
├── js/
│   ├── core/                  # النواة الأساسية (DB, Repos, Router, UI, Crypto, Charts)
│   ├── features/              # الميزات التفاعلية (Backup, Palette, Shortcuts, Badges, Reminders)
│   ├── ai/                    # محرك الذكاء الاصطناعي (AI Core, Agent Loop, System Prompt)
│   ├── tools/                 # أدوات الأسطى (112 أداة مقسمة حسب المجال)
│   ├── modules/               # شاشات المودولات الـ 21
│   └── app.js                 # إقلاع التطبيق وإدارة دورة الحياة
```

## 🚀 طريقة التشغيل

1. قم بتنزيل أو استنساخ المستودع:
   ```bash
   git clone https://github.com/luxorbookingdeveloper-hub/kollo.git
   ```
2. افتح ملف `index.html` في أي متصفح ويب حديث (Chrome, Edge, Firefox, Safari).
3. لا يتطلب أي تثبيت لـ `Node.js` أو `npm` أو سيرفر محلي.

## 🧪 الاختبارات الذاتية

يحتوي التطبيق على جناح اختبارات داخلية مؤتمتة hermetic لفحص سلامة قاعدة البيانات، منطق الحسابات المالية، خوارزميات التواريخ، ومحرك الذكاء الاصطناعي.
- يمكنك تشغيلها مباشرة بالانتقال إلى: `index.html#/tests` والضغط على **«▶️ شغّل كل الاختبارات»**.
